# 시나리오 2-08-5: 세션당 동시 실행 제한

**모듈:** 분산 환경 활용 > 서비스 거버넌스
**대상:** `llmd-pd/qwen38-int4-pd`, MaaS 구독 `models-as-a-service/llmd-demo-sub`
**상태:** 실행 중

## 목적

MaaS는 요청 시작 시 누적만 확인하므로, 동시에 시작한 장문 요청은 모두 통과한 뒤 한도를 크게 넘긴다(2-07 E2: 한도의 2.4배).
초과분은 다음 구간까지 같은 사용자의 모든 요청을 막는다. 본 시나리오는 클라이언트 측 동시 실행 수를 제한했을 때 초과량과
단문의 연쇄 429가 얼마나 줄어드는지, 그 대가로 완료 시간이 얼마나 늘어나는지 측정한다.

## 실험 설계

| 항목 | 값 |
|---|---|
| 한도 | 20,000/15초 (2-07 E2와 같음) |
| 장문 | 6건(약 12,100토큰), 동시 실행 4 / 2 / 1, 429 시 1초 후 재시도 |
| 단문 | 같은 API 키로 1초마다 새 요청(이전 요청 완료를 기다리지 않음), 장문 종료 후 5초까지 |
| 기록 | 한 구간 최대 차감량(한도 대비 배수), 단문의 429 수, 장문 6건의 완료 시간 |

동시 실행 제한은 MaaS 설정이 아니라 클라이언트(에이전트 프레임워크)의 세마포어로 구현한다.

```sh
cd openshift-ai-llmd-demo/harness
HARNESS_PROFILE=sno MAAS_MIT_ARMS=conc ./harness.sh scenario2-08-mitigation
```
