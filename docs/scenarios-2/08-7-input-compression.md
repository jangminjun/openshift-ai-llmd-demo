# 시나리오 2-08-7: 입력 압축(RAG 요약·reranker)의 효과 산정

**모듈:** 분산 환경 활용 > 서비스 거버넌스
**대상:** MaaS 구독 `llmd-demo-sub`
**상태:** 산정 대기(2-08 `io` 결과 필요)

## 목적

MaaS는 `usage.total_tokens`(입력 + 출력)로 차감한다. RAG 컨텍스트를 요약하거나 reranker로 상위 문서만 남기면 입력 토큰이
줄고, 같은 한도에서 처리할 수 있는 요청 수가 늘어난다. 압축은 애플리케이션 영역이므로 실험하지 않고, 2-08 `io`에서 확인한
차감 방식으로 효과를 산정한다.

## 산정 방법

한 구간에 통과하는 장문 수는 "누적 < 한도"인 동안 계속 통과하므로 `floor((한도 − 1) / 요청당 토큰) + 1`건이다(응답 후
차감). 차단 없이 연속 처리하려면 "요청당 토큰 × 구간 내 요청 수 ≤ 한도"가 필요하다.
